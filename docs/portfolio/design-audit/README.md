# Design audit 2026-10

Two-pass design audit of the hub, PaperLabs, Slop Editorial and Online Paluwagan. Proposed, not accepted. Read in this order.

1. [00-executive-summary.md](00-executive-summary.md): health, weaknesses, directions, order and decisions on two pages.
2. [06-open-decisions.md](06-open-decisions.md): the ten decisions only the owner can make, ordered by what they block.
3. [05-consolidated-priorities.md](05-consolidated-priorities.md): one implementation order across all roadmaps, with the critical path.
4. [04-cross-project-differentiation.md](04-cross-project-differentiation.md): how the four directions differ, dimension by dimension.
5. [01-universal-design-principles.md](01-universal-design-principles.md): the principles every finding is judged against.
6. [pass-1-register.md](pass-1-register.md): all 67 merged findings, strengths, uncertainties and Pass 1 conflicts.
7. [02-agent-a-brand-audit.md](02-agent-a-brand-audit.md): Agent A's Pass 1 brand and anti-slop audit with evidence.
8. [03-agent-b-ux-audit.md](03-agent-b-ux-audit.md): Agent B's Pass 1 UX, interaction and performance audit with evidence.
9. [pass-2-a-challenges.md](pass-2-a-challenges.md): Agent A's challenges to Agent B's audit.
10. [pass-2-b-challenges.md](pass-2-b-challenges.md): Agent B's challenges to Agent A's audit.
11. [pass-2-a-review-of-b.md](pass-2-a-review-of-b.md): Agent A's review of B's strategies.
12. [pass-2-b-review-of-a.md](pass-2-b-review-of-a.md): Agent B's review of A's strategies.
13. [pass-2-joint-calls.md](pass-2-joint-calls.md): five technical calls the lead settled without the owner.

Per project, each folder has `audit.md` (its slice of the register), `brand-strategy.md` (Agent A), `ux-strategy.md` (Agent B) and `implementation-roadmap.md` (combined):

- [portfolio/](portfolio/audit.md): the hub and the house.
- [paperlabs/](paperlabs/audit.md): PaperLabs.
- [slop-editorial/](slop-editorial/audit.md): Slop Editorial.
- [online-paluwagan/](online-paluwagan/audit.md): Online Paluwagan.
