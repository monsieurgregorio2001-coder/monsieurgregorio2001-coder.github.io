## Private workspace

Workspace `_career/` holds START-HERE.md, NOW.md, the candidate profile, claim register, base-document releases, per-job packets, the canonical tracker, event history, and review notes. It is outside the public portfolio repository. It has been initialized locally with no actual applications. It is not a remote backup or an installed tracking service.

The tracker records application state once. Job snapshots and final document hashes establish what a particular employer saw. Handover notes point to those records rather than copying application statuses. Public process changes belong here; personal preferences, salary details, employer correspondence, and live pipeline data belong in the private workspace.

## Execution authority

The current instruction is to plan and prepare a thorough handover. No outbound applications, emails, profile edits, reminders, or job-tracker service writes are part of this checkpoint. A successor should follow its actual execution instruction and any continuing user delegation. Do not invent a mandatory per-job approval rule when a clear delegation already covers the role, channel, and truthful packet. Missing factual answers, a changed scope, or a requested personal attestation must be resolved rather than guessed.
