## How agents run

- The lead session plans, briefs and reviews. Each row above goes to one Sonnet subagent with this file, DIRECTION, the repo's `AGENTS.md`, and the row as its brief.
- Every agent works on its own branch, runs that repo's checks, shoots screenshots for visual work, and reports what it verified and what it could not.
- The lead session reviews each report and diff before a PR is merged. No agent merges its own work.
- Agents never invent figures. A number appears only from a run in that agent's session or from `evidence.json`.
