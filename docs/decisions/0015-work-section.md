# ADR 0015: Work section as receipts

Status: proposed by Claude on the owner's delegation, 2026-10-20. Reversible.
Date: 2026-10-20

## Context

The phone page was long and proof came late. ADR 0003 card fields stay useful.

## Decision

ADR 0003 fields are shown as receipts. PaperLab gets a featured full-width receipt, as ADR 0004 asks. The other three sit in three columns from 1024 px and stack below that. There is no segmented control. Rows: Proves, Problem (120 characters or less), What I built (120 or less), Result (slot figure), Try this, How it is checked, and links to the room, the case, and the code.

This builds on ADR 0003.

## Consequences

- A shorter phone page and faster proof.
- See DIRECTION.md 5.6.
